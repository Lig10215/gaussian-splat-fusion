# 验证与验收

## 分层检查

1. **输入与格式**：原始模型/手工 edit 的 SHA 与工作版本一致；全量读取字段与激活约定正确、数据 finite、有效四元数、正尺度；PLY 头点数×每行字节与文件长度一致。未知格式明确失败。输出重新读取后 payload 与写入一致，原始输入 hash 未变化。
2. **配准**：报告 s/R/t，训练与独立留出控制点残差，检查多高度/多方向静态结构。保留相机上主殿门框、檐线、纪念碑、楼板一致。重复外墙、双台阶、双文字都视为失败，不接受平均位置“接近”。
3. **归属与保留**：每个必须来源确实贡献点；每个要求保留的实体列入 required_rows；provenance 无误且未复制同一 baseline 行。preserve 比较未改区域逐字段一致，只为明示行/列开放修改。SH0/1/2→3 提升后按规范通道比较。底稿不被偷偷缩放/改色。
4. **同机位视觉**：制作权威参考/修改前/修改后三列图。相机、视场、near、图尺寸一致；保留近处锐度与真实门洞/柱间通道，不用远处缩略图掩盖模糊。图片差异指标不等于结构真值。
5. **全场景遮挡**：按下面程序检查屋顶、广场楼板、水泥挡墙等真实不透明面。不能只单独渲染支撑层或报告“总 alpha 很高”。
6. **实际查看器**：用户指定的软件可打开新文件，点数/朝向正确，无属性/格式报错；查验近、中、远与俯视/平视/斜视。没有真正打开就明确“尚未在该查看器验收”，不能把参考渲染称为 OOOSplat 验证。

## 相机覆盖

按任务选择实际关键视图，不要求所有场景固定数量：
- 俯视主体屋顶：不能透出神像/红柱；保留原始瓦片及檐口。
- 广场两树间及楼板边的多角度：不能透出负一楼；真实楼梯/地坑开口应存在。
- 首层神龛、走廊正面与两侧：雕饰/对联/柱梁/台阶均保留；空气没有新增雾片。
- 纪念碑与平台：文字/栏杆/花池在原始地面模型中存在的细节仍可见。
- 题字墙正面、斜视、远近：只有一处字与一堵墙；墙沿和后方植被位置符合权威来源。
- 建筑后方植被及高处外观：没有来源误删导致黑洞，没有叠两份不同位置树冠。
- 地面室内各房间、负一楼及出入口：不能因去雾/加盖屋顶/提高亮度而丢房间、填门洞或遮住真实下楼通道。

## 反向染色/探针遮挡测试

测试前按实际物理边界定义有限面、相机、误差阈值和窄抗锯齿边缘裕量，记录在配置。不得看到失败后扩大掩膜排除失败区域。

**recolor**：从 provenance 或经核实的 indices 选择真实表面后的室内/地下点，只将 DC/SH 改为醒目的洋红，其他属性保持。在完整模型、相同相机中重新渲染，比较真实表面内部像素。如果颜色改变，隐藏点仍透出，测试失败。须验证选中的确是应隐藏内容，不能把屋顶本身的高斯误选为内部而制造假阳性。

**probe**：原来没有足够地下点可染色时，在已知面下放置足够远、足够密的诊断高斯。检查不会相交表面，也不写入交付文件。探针能暴露实际孔洞；单独改变模型背景只检测模型外背景，不足以验证楼层间遮挡。

记录 baseline/hidden/roi 图、选点数、测试像素数、超过 tolerance 的像素数、max/mean 差异。min_pixels 或选点数不足时应拒绝测试，不能空集算通过。局部边界抗锯齿只排除预先指定的窄边缘，真实孔洞不能被覆盖。

默认示例 tolerance=2/255、allowed_changed_pixels=0 只是参考，不是所有查看器的通用硬标准。以任务/渲染器噪声基线预先确定。CPU 中心深度排序是近似，结果只覆盖配置中的相机与面内部；还需在真实查看器检查，不能宣称任意角度绝不穿透。

失败时用 trace 找出差异区域真正贡献的 source/row，检查中心越界、巨型协方差、深度排序、缺失表面或错误选区。应修根因后按同一配置重测，不能只对一张图涂抹。

## 建议交付清单

- 新版本 PLY 和 SHA256、点数、字节数、坐标/激活说明；
- 配准矩阵、独立控制点报告、source hash 和 ownership 配置；
- 来源 source_id/source_row NPZ 与对应 source 列表，局部删改记录；
- 格式回读、关键行保留报告；
- 参考/旧版/新版同机位图，相机 JSON；
- 遮挡配置、报告与诊断图；
- 已在查看器验证的事实，以及仍受原始数据模糊/缺测限制的部分。

发现失败时保持原稿不变，修订新版本；不把“能打开”“自动测试通过”或单机位好看等同于用户要求全部完成。
