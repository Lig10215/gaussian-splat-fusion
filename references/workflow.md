# 工作流与决策

## 1. 建立可复现输入

记录文件绝对路径、大小、点数、SHA256、字段约定、相机来源、人工编辑底稿和当前版本。保存旧模型，输出独立版本目录；不要全盘递归寻找大文件。读取输入只需本地文件系统，不依赖联网、数据库写入或 GUI。

有 COLMAP 时记录每次导出的 PLY 与 sparse、database.db 的对应关系，以及编辑器额外的导出矩阵 E。SfM 估计 T 把地面原生坐标映射至航拍原生坐标时，导出后的变换为：
`M = E_aerial @ T @ inverse(E_ground)`。
编辑器的平移/旋转/缩放不能遗漏。手动 edit.ply 与上一版本也可能不同尺度；用可追溯点确认，不拿文件名当坐标证据。

inspect 的 sample_bounds 只是前一万点样本，不是完整包围盒。需要完整统计时遍历 SplatFile.chunks()。对异常点用稳健分位数与实际视图，不直接把全部极值当建筑范围。

## 2. 求变换并验证

1. 优先从匹配的 COLMAP sparse+SQLite 读取 SIFT 轨迹特征；match-colmap 产生候选三维对应点。它们仍可能落在树叶、车辆、重复红柱或错误三角化上。
2. 对称建筑同时检查左右顺序、层高、门洞、纪念碑和屋脊。选分布于多个高度/方位的静态控制点。把真正未参与拟合的可信点标为 trusted_holdout_indices。
3. fit-pairs 使用正尺度 Sim(3) RANSAC，阈值用目标坐标单位。先确认单位和预期结构精度，再设阈值。随机保留的候选匹配不是独立真值。
4. 用独立相机看墙脚、檐口、门框和楼层；报拟合与控制点 p50/p95/max、尺度和残差分布。局部树叶的低误差不能掩盖门框错位。
5. 需要时在共同静态结构掩膜内做 initialized ICP，固定尺度。不得让未重叠区域、鱼眼拉伸、植物或地下层主导配准。低 ICP RMSE 不能证明结构正确。
6. 地面模型局部非刚性畸变超出可接受范围时，按区域选择可靠数据或回到校准/重建，不用非均匀缩放扭曲权威建筑。本工具仅支持正尺度刚体相似变换，不提供自动鱼眼重训练。

只有 PLY、没有相机/轨迹时，可人工标注跨模型对应点与同机位视图。重叠不足不能可靠求变换时明确停在证据缺口，不宣称自动完成。

完整参数运输：
`p'=s R p+t; log_sigma'=log_sigma+log(s); Q'=R Q; Sigma'=s² R Sigma Rᵀ`。
真实 SH 系数按方向旋转，DC 不旋转；相机 `C'=sRC+t, Rcw'=Rcw Rᵀ`。只变换 XYZ 会造成扁片方向、尺度和视角颜色错误。

## 3. 设计单一所有权

制作实体清单，例如：主体屋顶/外墙、写字挡墙、铺地、植物、神龛、红柱走廊、纪念碑、1F 房间、B1 房间。每项记录权威来源、范围和检查相机。

融合配置的 frame 只用于空间查询，输出仍保留底稿坐标。basis 的列为查询坐标的 X/Y/Z 单位轴，q=(p-origin)@basis。按实际建筑定义局部高程；拱廊、地下室与楼板需要有限三维体积，不是无界二维投影。

default_owner 通常是用户的底稿。每个 bounded ownership 区域覆盖其中的来源选择，priority 解决重叠。边界需要覆盖同一实体在不同采集中发生的小偏移，避免旧墙留在选择区外产生第二堵墙；也不能扩大到相邻真实结构。不同来源同优先级冲突会报错。

对于地面-1详细神龛/柱子/碑廊，给出包住真实物体的区域而不是全局高度粗切。对于航拍铺地与地面室内的交界，区域止于实际楼板/屋顶；真实出入口与下楼通道另分区域。凹多边形/孔洞拆成凸区域，不做凸包封掉楼梯或露天庭院。

默认硬归属防止叠两层外墙；不要直接 concatenate 全部采集。若必须过渡，先证明单表面对齐、测试透明度与重影，本工具不自动猜测软混合带。selection=append 仅允许显式 generated_support，不能绕过所有权把整份地面数据叠回去。

## 4. 修复与局部追踪

**浮影**：结合来源、邻近真实表面距离、协方差尺寸/各向异性、原始相机支持及多个方向可见性判断。在限定空气体积中处理低支持点；不要按“红/黑/白颜色”全删。先查看各来源单独效果，避免把过曝地面与真实水泥墙误判成雾。

**透明面**：先还原被误删的权威表面、修正重复/错位面、检测地面点协方差穿屋顶，再考虑测量支撑薄层。ceiling 可裁中心并压缩法线协方差，但中心排序仍可能造成可见泄漏，必须全场景测试。支撑层位于真实屋顶/地面细节下，不能铺到空气中或盖住原始纹理。shell 仅支持显式平面/双坡平面下包络，不恢复未知曲面。

**文字**：trace 从指定相机的像素掩膜统计可见 alpha 贡献；再结合 source_id/source_row 与空间区域筛选文字本体。候选排名不等于语义文字，必须查看选中点，保护墙沿与背景。先复核原始来源的同机位效果；只有局部 SH/alpha 问题时才用 material 以可信相机颜色固定局部 SH 或调 alpha。保留唯一几何，检查邻近墙色与远近斜视，不能新增复制文字遮住问题。

**亮度**：按房间和曝光证据估计有限增益，保留黑位与红柱、神像颜色；不是全模型提高 opacity/DC。material 的 gain 是对模型编码 RGB 的乘法，不是带相机响应曲线的真实 HDR 统一。

所有局部索引与掩膜绑定模型 SHA256；换版本重新映射。几何/点顺序变化后更新 provenance，不能沿用错误行号。material 不改顺序，可复制原 provenance 并记录父版本；自定义删点必须同步删除 provenance 中相同行。

## 5. 交付

运行 verification.md 的检查。保存 job、矩阵、原始文件 hash、来源行映射、增删改记录、相机 JSON、测试阈值及图片。新模型通过原子写入和重新读取再交付。可另产 ASCII 路径副本供特定查看器兼容，但需 hash 证实同一内容，不能假定中文路径就是历史报错原因。
